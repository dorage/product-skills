# 결론을 먼저 놓는다

읽는 사람은 첫 두 쪽에서 판단을 끝낸다. 표지 다음 쪽에 결론을 세 문장 이하로 적고, 나머지 쪽은 그 결론을 받치는 근거로만 쓴다.

- 결론 쪽의 문장마다 그 근거가 있는 쪽 번호를 옆에 적는다
- 마지막 쪽은 새 이야기를 꺼내지 않고, 읽는 사람이 정해야 할 것으로 끝낸다

나쁜 예: 배경 → 경위 → 분석 → 결론 순서로 10쪽을 넘긴 뒤에야 요청이 나온다.

좋은 예:
```
2쪽 결론
- 지금 주문 처리 방식은 달마다 오류가 늘고 있습니다 (3~4쪽)
- 새 시스템으로 바꾸면 오류 처리 시간이 줄어듭니다 (5~9쪽)
- 도입 시기와 예산을 정해 주셔야 합니다 (10~12쪽)
```
