# 요청은 읽는 사람이 정할 수 있는 항목으로 끝낸다

마지막 쪽은 "검토 부탁드립니다"가 아니라, 읽는 사람이 그 자리에서 예 또는 아니오로 답할 수 있는 항목이다. 항목은 세 개 이하로 둔다.

- 선택지가 있으면 둘을 나란히 놓고 각각의 값을 적는다
- 추천안 하나를 분명히 적는다. 마지막 쪽에 숨기지 않는다
- 분석은 내 일이고 결정은 읽는 사람의 일이다. 위험을 안고 가는 선택은 그 위험을 지는 사람의 승인을 받는 항목으로 적는다

나쁜 예: "개선 방안을 검토해 주시기 바랍니다."

좋은 예:
```
정해 주실 것
- 시기: 새 시스템을 이번 분기에 들일지
- 예산: 도입 비용을 올해 예산에서 쓸지
- 담당: 전환을 어느 팀이 맡을지
```
