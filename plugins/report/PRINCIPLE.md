# 원칙 목록

report 플러그인의 스킬이 지키는 원칙의 목록이다. 내용은 `principles/` 의 원칙 문서에 있고, 여기에는 목록만 둔다. `[[이름]]` 은 `principles/{이름}.md` 를 가리킨다. 어떤 스킬이 어떤 원칙을 쓰는지는 각 `SKILL.md` 의 「적용하는 원칙」 표에 있다.

## 내용에 관한 원칙

- [[conclusion-first]] - 결론을 먼저 놓는다
- [[non-overlapping-evidence]] - 근거는 겹치지 않게 묶는다
- [[details-below]] - 세부는 아래로 내린다
- [[cite-source-and-page]] - 숫자와 인용에는 출처와 쪽 번호를 붙인다
- [[evidence-reader-trusts]] - 읽는 사람이 이미 믿는 자료에서 근거를 가져온다
- [[facts-not-judgment]] - 사람을 평가하지 않고 일과 사실을 적는다
- [[written-vs-spoken]] - 문서에 쓸 것과 말로 할 것을 나눈다
- [[decidable-ask]] - 요청은 읽는 사람이 정할 수 있는 항목으로 끝낸다
- [[verify-with-numbers]] - 다 만든 뒤 숫자로 검사한다
- [[price-the-claim]] - 주장에 값을 매긴다
- [[label-estimates]] - 추정은 추정이라고 적고 어떻게 구했는지 댄다
- [[progress-not-activity]] - 활동량이 아니라 진척을 보인다
- [[readers-words]] - 읽는 사람의 말로 쓴다
- [[polish-without-mark]] - 문장은 윤문하되 윤문 기록은 자료에 적지 않는다

## 쪽 모양에 관한 원칙

- [[three-colors]] - 색은 세 가지만 쓴다
- [[highlight-limit]] - 하이라이트는 한 쪽에 세 문장까지만 쓴다
- [[highlight-only-readable]] - 하이라이트만 읽어도 전체가 이해된다
- [[chart-shows-signal]] - 차트는 한눈에 보여야 할 신호가 있을 때만 넣는다
